\section{Referring Equations}
This section illustrates, how to refer Equations.

This is how equation $$ F = ma $$ is centered and not referred.

To get equation in the same line, use this $ z^2 = x^2 + y^2$ which is called Pythagorous Equation.


\begin{equation} 
\label{eq:ohm}
V=IR
\end{equation}

where,\\ $V=voltage,\\ I=current $ and $\\ R=resistance $ \\
The equation \ref{eq:ohm} is a called Ohm's equation.
