Project Info
Model Architecture

Graph Attention Network (GAT) trained on network traffic flows represented as dynamic graphs. Learns to detect coordinated multi-flow attack patterns that traditional ML models miss.

Input
79 features per flow (CICIDS2017)
Output
Binary — Normal / Attack + confidence
Dataset
Dataset
CICIDS2017
Features
79 network flow features
Train set
27,836 samples (23,195 normal / 4,641 attack)
Test set
5,965 samples (4,970 normal / 995 attack)
